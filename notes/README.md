# Historical / Reference Notes

The files in this directory are preserved because they contain useful material from earlier study.

They are **not the canonical progress tracker**.

Some notes contain statements such as "completed" or "what I learned". Those statements describe earlier study sessions and do not automatically prove current mastery under the active learning system.

Use these files for:

- review
- examples
- terminology
- comparison with current learning

Do not use them to skip a mastery gate.

Canonical status lives in:

- [../PROGRESS.md](../PROGRESS.md)
- [../LEARNING_SYSTEM.md](../LEARNING_SYSTEM.md)

As new topics are verified, canonical phase artifacts will be added under `phases/`, `exercises/`, `tests/`, and `projects/`.
