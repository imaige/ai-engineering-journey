# PHASE 1 — Python Programming

Status: **IN_PROGRESS**

Started: **2026-09-20**

## Objective

Build strong Python programming fundamentals for later AI engineering work. The target is not syntax memorization. The learner must be able to reason about code, write it independently, debug it, explain why it works, and solve small practical problems.

## Topic Order

1. Python execution model and source-code flow
2. expressions vs statements
3. names, objects, references and identity
4. core built-in types
5. operators and comparisons
6. truthiness and boolean logic
7. conditionals
8. loops and iteration
9. strings
10. lists and tuples
11. dictionaries and sets
12. comprehensions
13. functions, parameters, return values and scope
14. modules, packages and imports
15. exceptions
16. file I/O and context managers
17. classes and OOP fundamentals
18. dunder methods and data model basics
19. type hints
20. testing and debugging
21. practical mini-projects
22. final review and mastery gate

## Evidence Policy

Historical files under `notes/python/` are reference material. They do not automatically count as current mastery.

For each major area, evidence may include:

- explanation in the learner's own words
- prediction of code output
- code written independently
- debugging tasks
- small exercises
- review questions
- mini-projects

## Completion Rule

Phase 1 is marked `PASSED` only after required practice is complete and the final mastery gate reaches at least 90%.
